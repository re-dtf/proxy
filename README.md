# reDTF Auth Proxy

Минималистичный прозрачный CORS-прокси для авторизации в [reDTF](https://github.com/re-dtf/client). 

## Зачем это нужно?

Проект reDTF спроектирован как **100% статичное клиентское приложение** (SPA), чтобы любой мог убедиться в отсутствии воровства данных и паролей. Приложение хостится на статичном сервере GitHub Pages, который не умеют выполнять бэкенд-код.

Официальный API DTF (`api.dtf.ru`) имеет жесткую политику безопасности (CORS) на эндпоинте входа по Email/Паролю. Браузер блокирует попытки отправить пароль напрямую с стороннего сайта.

Чтобы обойти это ограничение, нужен прокси. Вы можете:
1. Воспользоваться прокси от автора проекта (автоматически в приложении). К сожалению, хоть я и гарантирую 100% надежность, обеспечить его полную прозрачность физически невозможно. Если вы боитесь за свой аккаунт и не доверяете сторонним сервисам, лучше использовать второй способ.
2. Развернуть этот микро-сервис на своем аккаунте Cloudflare бесплатно за 2 минуты. Это гарантирует, что ваши данные проходят только через ваши руки. 

Код прокси состоит всего из ~30 строк (см. `src/index.ts`) и просто добавляет заголовок `Access-Control-Allow-Origin: *` к ответу сервера DTF. Ничего не логируется и не сохраняется.

## Инструкция по развертыванию

Вы можете развернуть прокси используя только браузер.

1. Зайдите в панель управления [Cloudflare Dashboard](https://dash.cloudflare.com/) и войдите в ваш аккаунт, если потребуется.
2. В левом меню разверните раздел **Compute**, затем перейдите в **Workers & Pages**.
3. Нажмите кнопку **Create application**.
4. В появившемся меню нажмите **Start with Hello World!**.
5. Просто нажмите **Deploy**.
6. Нажмите **Edit Code** (кнопка в правом верхнем углу).
7. В открывшемся редакторе полностью удалите стандартный код и вставьте содержимое файла `src/index.ts` из этого репозитория.
8. Нажмите **Deploy** в правом верхнем углу.
9. Скопируйте полученную ссылку (находится справа сверху недалеко от кнопки Deploy, вида `https://random-name.<ваш-аккаунт>.workers.dev`) и вставьте её в приложении reDTF (на странице входа в настройках CORS-прокси).

Готово! Теперь вы можете безопасно логиниться по паролю через собственный шлюз, и отслеживать путь своих данных от начала до самого конца.
