# reDTF Auth Proxy

Минималистичный прозрачный CORS-прокси для авторизации в [reDTF](https://github.com/re-dtf/client). 

## Зачем это нужно?

Проект reDTF спроектирован как **100% статичное клиентское приложение** (SPA), чтобы любой мог убедиться в безопасности своих данных. Приложение хостится на статичном сервере GitHub Pages, который не умеют выполнять бэкенд-код.

Официальный API DTF (`api.dtf.ru`) имеет жесткую политику безопасности (CORS) на эндпоинтах авторизации (вход по Email/паролю, обновление токена) и поиска. Браузер блокирует эти запросы со стороннего сайта.

Чтобы обойти это ограничение, нужен прокси. Вы можете:
1. Воспользоваться официальным прокси reDTF (автоматически в приложении). Он работает на val.town и является публичным, то есть вы можете посмотреть каждую строку кода, которая работает именно сейчас, а также все изменения.
2. Развернуть этот микро-сервис на своем аккаунте val.town бесплатно за 2 минуты. Это гарантирует, что ваши данные проходят только через ваши руки. 

Код прокси компактный (см. `src/proxy.ts`), не логирует данные и защищён от злоупотреблений:
- **Белый список методов и путей**: разрешены только `/v3.4/auth/email/login` (POST), `/v3.4/auth/refresh` (POST) и поиск `/v2.10/search/posts`, `/v2.51/search/subsites` (GET). Все остальные запросы отклоняются (403).
- **Ограничение размера**: тела POST-запросов ограничены 32 КБ (413).
- **Защита от флуда (Rate Limiting по IP)**:
  - Вход по почте/паролю: не более 5 запросов за 30 минут.
  - Обновление токена: не более 2 запросов за минуту.
  - Поиск: не более 5 запросов за 10 минут.

## Инструкция по развертыванию

### Вариант 1. Val Town (рекомендуется)

1. Зайдите на [Val Town — redtf-proxy](https://www.val.town/x/donnertech/redtf-proxy) и авторизируйтесь любым удобным способом (например, через Google или GitHub), пройдите опросник любыми вариантами и выберите Free план.
2. (Опционально) Можете ознакомиться с текущим кодом, убедившись что он чист.
3. Нажмите Remix.
5. После успешного Remix перед вами должен быть Val, который теперь принадлежит вам. Скопируйте полученный веб-адрес (вида `https://<ваш-логин>-<название>.web.val.run`).
6. Вставьте полученную ссылку в приложении reDTF.

Этот инстанс полностью зависит от вас, и не может обновляться без вашего ведома.

---

### Вариант 2. Cloudflare Workers
*Классический вариант на инфраструктуре Cloudflare.*

#### Через терминал (быстрее всего):
1. Склонируйте репозиторий: `git clone https://github.com/re-dtf/proxy.git && cd proxy`
2. Выполните: `npm install`
3. Задеплойте: `npm run deploy` (Wrangler автоматически соберёт `cloudflare.ts` и `proxy.ts` в единый бандл).
4. Скопируйте выданный адрес `*.workers.dev` в настройки reDTF.

#### Через браузер (Cloudflare Dashboard):
1. В панели [Cloudflare Dashboard](https://dash.cloudflare.com/) перейдите в **Compute** &rarr; **Workers & Pages**.
2. Нажмите **Create application** &rarr; **Start with Hello World!** &rarr; **Deploy**.
3. Нажмите **Edit Code**.
4. В файловой структуре слева добавьте `proxy.ts` (содержимое [`src/proxy.ts`](src/proxy.ts)), а в главный файл вставьте [`src/cloudflare.ts`](src/cloudflare.ts).
5. Нажмите **Deploy** и скопируйте URL вида `https://<имя>.<аккаунт>.workers.dev`.
